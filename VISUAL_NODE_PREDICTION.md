## Example 3: Function Definition

    return total / len(data)

## Node Color Legend

| Category | Color (RGB) | Example Nodes |
|----------|-------------|---------------|

This visual prediction shows the expected node layout when converting Python code
to PyFlow visual scripts. Each construct maps to specific node types with proper
pin connections for both execution flow (white wires) and data flow (colored wires).
